# HardyOS brand assets

| File | Use |
| --- | --- |
| `hardyos-logo-horizontal.svg` | Full logo with wordmark and tagline (dark background built in) |
| `hardyos-icon.svg` | App icon: the mark on its rounded tile |
| `hardyos-mark.svg` | The mark without a background, for dark surfaces at 28 px and up |
| `hardyos-mark-small.svg` | Simplified mark for small sizes (menu bar, footers): no thin crossbars or traces |
| `hardyos-favicon.svg` | Browser-tab icon: tile plus the simplified mark |

Colors: cyan `#00F0FF` to violet `#8B5CFF` gradient on `#05070F`.
The web desktop serves copies from `web/apps/shell/public/brand/`; keep them in sync.
